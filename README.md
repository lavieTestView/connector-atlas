# Connector Atlas

Connector selection tool for Testview cable / harness design – D38999, D-sub, BNC and TNC.
Search by part number or by need (wires, mounting, gender, angle, pins) and get the backshell, mating part,
contacts, finish, Visio side / front views and live DigiKey / Mouser stock and prices.

- `index.html` – the page (never edited for new connectors)
- `catalog.js` – every connector, family and question
- `live_data.js` – DigiKey / Mouser data, refreshed weekly
- `img/` – side and front views (from manufacturer catalogs)

Maintained from the ConnectorSelector folder; this repository is a published copy.
